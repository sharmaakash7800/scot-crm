🚀 How to Upload to GitHub

A clean .gitignore and README.md are already set up. Open terminal and run: 

git init
git add .
git commit -m "Initial commit: SCOT Sales Tracking Web App with MongoDB"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main

* Note: MongoDB Atlas credentials can be placed in .env which is safely gitignored!

📋 Google Apps Script (2-Way Auto-Sync)

CRM me save hua data Google Sheet me row bankar add ho jayega

Sirf 3 steps me setup karein:
1. Google Sheet me Extensions > Apps Script open karein.
2. Yeh code paste karein aur Deploy > New deployment > Web app select karein.
3. Who has access: "Anyone" karke deploy karein aur Webhook URL CRM me daal kar "Save Webhook" click karein!
